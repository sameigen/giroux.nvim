## Findings selected but NOT planned this pass

The audit surfaced more than these twelve. The following were considered and
**deliberately deferred** (recorded so they aren't re-audited as new):

- **feed.lua god-module split (DEBT-02, L, MED-risk)** — `feed.lua` (980 lines)
  mixes rendering, transport, fold UX, and question polling. Real debt, but a
  risky L refactor that should land *after* the transport half has integration
  coverage (see TESTS-02). Deferred until 001/002/005 stabilize the surrounding
  code.
- **feed transport unit coverage (TESTS-02, L)** — the monitor-vs-own-tail
  switch, offset-guarded replay, and `skip_partial` math are only covered by
  platform-gated integration specs. Worth extracting the offset-guard predicate
  to a pure helper and unit-testing it; deferred as an L effort.
- **window/compose-split boilerplate dedup (DEBT-03, M)** — clean-window +
  scratch-buffer + compose-split idioms are copy-pasted (and drifted) across
  `feed`/`roster`/`qa`/`statsheet`/`dispatch`/`steer`. A `giroux.ui` helper would
  fix it; M effort, deferred behind the bug work.
- **tmux/osascript escaping (SECURITY-02/04, low reach)** — `tmuxctl.rename-session`
  and `notify.osascript` interpolate model-generated names/titles without the
  shared quoter. Upstream sanitizers make breakout hard, so low priority; fold
  into the 002 follow-up (dedupe `shq` into `ssh.shq` and apply everywhere).
- **auth token in `curl` argv (SECURITY-03, S, low materiality)** — `health.lua`'s
  probe passes the token as a `curl -H` argument (visible via `ps`/`/proc` for
  ~8s). Real but low-impact on a single-operator tailnet; a clean S fix
  (`curl -K -` config on stdin) worth doing opportunistically, not urgent.

## Direction options NOT turned into plans (maintainer's call)

Grounded roadmap items from the intent docs. Left as options rather than plans —
they're larger design efforts to choose deliberately:

- **Tier-2/3 diffs (DIRECTION-01, L)** — `v` → `ssh git diff` into a diff buffer
  (tier 2, M), then the rsync-on-demand file cache (tier 3, harder). The last
  unbuilt item of the original build order; DESIGN §9/§14 promise it and the
  stubs are explicit (`statsheet.lua:159` "remote open not yet wired"; the `v`
  keymap is reserved but unwired). Plan 005 hardens the open path it hooks into.
- **Parole PR handoff (DIRECTION-02, M)** — feed detects "PR opened" → offers
  `:Parole <url>`. The pipeline both READMEs advertise; the `gh pr` output
  already streams through the parser; no code exists yet. Design-spike shaped.
- **`:GirouxClean` worktree pruning (DIRECTION-04, M, destructive)** — dispatch
  always creates a worktree but `clean()` only reaps tmux, leaking checkouts.
  Needs a merged/idle safety gate before it deletes anything.
- **ntfy push notifications (DIRECTION-05, S-M)** — a Linux operator currently
  has no external notify path (osascript degrades to in-editor `vim.notify`).
  One HTTP POST behind the existing `channel()` seam. "Phase 2" in DESIGN §6, so
  possibly a deliberate defer.
- **Roster written/read activity column (DIRECTION-06)** — DESIGN §14 promises
  `✎3 ⊙27` per row but it's unbuilt. **Not worth doing** until the monitor gains
  per-session stats aggregation for another reason — surfacing accurate counts
  means full-parsing each session or threading `stats` into the monitor, which is
  why it's been deferred. Low leverage; the statsheet (`S`) already gives the
  full breakdown.

Selected direction item this pass: **012 (finish pick.lua migration)** — the one
mechanical, low-risk direction win, chosen because it closes a migration already
half-done in the working tree.
